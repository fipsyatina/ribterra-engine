## What was actually added

- [Shared local-visibility HLSL](../../shaders/local_occlusion.hlsli) intersects the `P + N*bias → light` segment with authored XY+height OBB/capsule geometry. Visibility multiplies only the diffuse/specular contribution of the corresponding local source. Ambient light, sunlight, emission, and UI receive no global darkening.
- Authored prism templates flow from [master](../../art-source/engine-calibration/material-master.json) → [exporter](../../tools/export_material_master.py) → schema2 → transactional [GameArt](../../src/client/game_art.cpp) → camera-relative `Frame2D`. They are not derived from caster-mask pixels. The exporter canonicalizes geometry to float32 before validation so CPU/GPU receive the same accepted prism.
- Owner-aware self-exclusion: a receiver and its own prism share the same non-zero owner id; only that prism is bypassed. Foreign and mixed blocker lists remain effective. With `reveal<1`, hidden geometry is removed before IDs and budget/upload are assigned.
- A separate per-slot storage buffer exists in the production [Renderer2D](../../src/render/renderer2d.cpp); the slot fence completes before reuse/upload. Vertex/index/surface/occluder growth candidates are committed together only after successful allocation. Shutdown waits for GPU completion before release.
- An empty small list uses an initialized dummy64 for a valid SDL binding, but count0 and no shader read. Telemetry includes these actual 64 upload bytes. This adds no new target/pass: the graph remains `GroundGBuffer → GroundLighting → WorldForward → Composite → UI`.

## GPU and geometry contract

`OccluderGpu`64, align16, offsets0/16/32/48; shape flags — `(1 OBB / 2 capsule, revealed1, stableId, ownerId)`. Versioned use of the former reserved owner word and exact component layouts is given in [Core §6](RENDER_CORE_SPEC_UA.md). Forward metadata32 consists of reveal float4 and receiver uint4; SpriteSurface160, LightGpu80 and lighting384 are unchanged.

GroundLighting: four samplers, one uniform, one fragment storage buffer `t4,space2`. WorldForward: five samplers, three uniforms, one fragment storage buffer `t5,space2`. SDL fragment-storage binding index — 0 in both, this is not HLSL texture register number. Legacy material — five samplers/two uniforms/zero storage, without local ranges.

Pinned SDL3.4.16 D3D12 uses RAW SRV; shadercross3.0.0-preview.2 SPIR-V round-trip provides compatible lowering. [SDL RAW SRV implementation](https://github.com/libsdl-org/SDL/blob/fa2c02bb6e21974a89ea9824bc53c9932abe5f9c/src/gpu/d3d12/SDL_gpu_d3d12.c#L3898-L3922), [shadercross implementation](https://github.com/libsdl-org/SDL_shadercross/blob/1ca46e0ef7a9e50c706e7be6ef73ce467bac3b2e/src/SDL_shadercross.c#L574-L627), [D3D12_BUFFER_SRV contract](https://learn.microsoft.com/en-us/windows/win32/api/d3d12/ns-d3d12-d3d12_buffer_srv). Exact DXIL guards check for a specific RAW resource handle, record stride64, offsets, and record count, not just the presence of struct declaration. Negative tests include incorrect bindings/space/MRT/ABI, stale hashes, noncanonical includes, owner word, capsule axis/stride, and intersection math.

This step is bounded to max256 global /32 per-light, minimum dimensions `1e-4`, and a GroundForward domain of ±32 for P/light anchors/prism footprint/Z. Overflow, invalid ranges/axes/IDs/flags/NaN/minimum dimensions fail closed **before** GPU submission; nothing is silently dropped. The caps, O(pixels×lights×blockers) cost, culling/acceleration, and approximation quality **are not measured optimization results**. The capsule perpendicular is derived from normalized axis X; circle intersection uses closest-point math, separate physical-inset and segment-endpoint epsilons, and a strict nonzero interval.
