Повний двигун НЕ ПРИЙНЯТО.** Opt-in `GroundForwardSlice` тепер перекриває окремі локальні point/spot джерела authored OBB/capsule prisms. ## Що реально додано

- [Shared local-visibility HLSL](../../shaders/local_occlusion.hlsli) перетинає відрізок `P + N*bias → light` із authored XY+height OBB/capsule. Видимість множить лише diffuse/specular внесок відповідного локального джерела. Ambient, сонце, emission і UI не отримують загального затемнення.
- Authored prism templates проходять [master](../../art-source/engine-calibration/material-master.json) → [exporter](../../tools/export_material_master.py) → schema2 → transactional [GameArt](../../src/client/game_art.cpp) → camera-relative `Frame2D`. Не виводяться з pixels caster mask. Exporter canonicalizes geometry до float32 перед перевірками, щоб CPU/GPU отримували той самий прийнятний prism.
- Owner-aware self-exclusion: receiver і його власний prism мають однаковий ненульовий owner id; тільки цей prism пропускається. Чужий і змішаний blocker списки залишаються дієвими. При `reveal<1` прихована геометрія виключається до призначення IDs і budget/upload.
- Окремий per-slot storage buffer у production [Renderer2D](../../src/render/renderer2d.cpp); slot fence завершується до reuse/upload. Vertex/index/surface/occluder growth candidates встановлюються разом лише після успішного allocation. Shutdown чекає завершення GPU перед release.
- Малий відсутній список має initialized dummy64 для валідного SDL binding, але count0 і жодного shader read. Telemetry враховує ці фактичні 64 upload bytes. Це не новий target/pass: graph лишається `GroundGBuffer → GroundLighting → WorldForward → Composite → UI`.

## GPU та геометричний контракт

`OccluderGpu`64, align16, offsets0/16/32/48; shape flags — `(1 OBB / 2 capsule, revealed1, stableId, ownerId)`. Версійоване використання колишнього reserved owner word і exact component layouts наведено в [Core §6](RENDER_CORE_SPEC_UA.md). Forward metadata32 складається з reveal float4 та receiver uint4; SpriteSurface160, LightGpu80 і lighting384 незмінні.

GroundLighting: four samplers, one uniform, one fragment storage buffer `t4,space2`. WorldForward: five samplers, three uniforms, one fragment storage buffer `t5,space2`. SDL fragment-storage binding index — 0 в обох, це не HLSL texture register number. Legacy material — five samplers/two uniforms/zero storage, без local ranges.

Pinned SDL3.4.16 D3D12 використовує RAW SRV; shadercross3.0.0-preview.2 SPIR-V round-trip забезпечує сумісне lowering. [SDL RAW SRV implementation](https://github.com/libsdl-org/SDL/blob/fa2c02bb6e21974a89ea9824bc53c9932abe5f9c/src/gpu/d3d12/SDL_gpu_d3d12.c#L3898-L3922), [shadercross implementation](https://github.com/libsdl-org/SDL_shadercross/blob/1ca46e0ef7a9e50c706e7be6ef73ce467bac3b2e/src/SDL_shadercross.c#L574-L627), [D3D12_BUFFER_SRV contract](https://learn.microsoft.com/en-us/windows/win32/api/d3d12/ns-d3d12-d3d12_buffer_srv). Exact DXIL guards перевіряють конкретний RAW resource handle, record stride64, offsets і record count, а не лише наявність struct declaration. Negative tests охоплюють неправильні bindings/space/MRT/ABI, stale hashes, noncanonical includes, owner word, capsule axis/stride та intersection math.

Обмеження цього кроку: max256 global /32 per-light, min dimensions `1e-4`, GroundForward domain ±32 для P/light anchors/prism footprint/Z. Overflow, invalid ranges/axes/IDs/flags/NaN/min dimensions fail-closed **до** GPU submission; нічого не відкидається мовчки. Caps, O(pixels×lights×blockers), culling/acceleration та якість approximation **не є виміряною оптимізацією**. Capsule perpendicular виводиться з normalized axis X; circle intersection використовує closest-point math, окремі physical inset і segment-endpoint epsilons, strict nonzero interval.
