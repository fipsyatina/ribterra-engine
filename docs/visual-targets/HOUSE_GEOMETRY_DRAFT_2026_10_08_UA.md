# Чернетка геометрії будинку

Незалежний огляд джерел підтвердив узгоджену геометрію `building.house.ready` після виправлення стовпчиків і відра. Це чернетка для наступної роботи з матеріалами; експорту, запуску на GPU та приймання відповідності референсам ще немає.

| Перевірене в джерелах | Результат |
|---|---|
| Трикутники / landmarks / поверхні | 114 / 206 / 53 |
| Числові probes / семантичні samples | 20 / 52 |
| Максимальна похибка зворотної проєкції | 5.684 × 10⁻¹⁴ px |
| Планарність стовпчиків | residual ≤ 2.263045 × 10⁻¹⁶ units; розбіжність нормалей ≤ 0.000001479° |
| Відро | спільне кільце з 8 вершин, верхня грань +Z, чотири вертикальні грані з кутом 45° між сусідніми |
| Пікселі alpha>0, покриті геометрією | 127 563 із 147 212 |
| Пікселі alpha>0 без геометрії | 19 649; усі 1 829 RLE-runs незалежно перевірено |

Оригінальне зображення, crop, pivot, reference_width, provenance та notices збережено. У старому арті є намальоване освітлення й ореол. Геометрія не отримала штучних поверхонь лише для покриття цих пікселів. Отже, чернетка ще не проходить обов’язкову для painted-експорту умову покриття кожного alpha>0. Потрібен окремий нейтральний матеріальний арт із чесно визначеним силуетом і перевіркою прив’язки у звичайному GameView.

Застосовані камера, масштаб і фізичні розміри є авторськими припущеннями, описаними в `GEOMETRY_ASSUMPTIONS_UA.md`; числова узгодженість із ними не доводить відновлення форми зображеного об’єкта. Верхні краї стовпчиків зберігають задані screen outlines; їхні висоти не оголошено виміряними фізичними даними.
