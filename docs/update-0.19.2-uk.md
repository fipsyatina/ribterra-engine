# Ribterra 0.19.2

Кожен сезон триває 30 ігрових днів (один місяць): весна 1–30, літо 31–60, осінь 61–90, зима 91–120. На 121-й день знову починається весна.

Інтерфейс, сезонні текстури й зимові правила використовують спільний календар. У старих збереженнях сезон визначається за поточним ігровим днем за новою тривалістю. Правила 13; попередні збереження підтримуються.
