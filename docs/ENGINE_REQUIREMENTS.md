# Complete Ribterra Engine: Requirements and Acceptance Evidence

> English translation of the historical document; snapshot-specific evidence and scope are preserved from the original wording imported in commit `7388a2f`.

Active objective: implement the complete engine defined by `Ribterra_Development_and_Steam_Plan_UA.docx`, revision 1.4. The initial M0 and the later server foundation are intermediate states. The objective is incomplete until every mandatory row below has current executable evidence. “The file exists,” “the dependency is installed,” or “the library compiles” does not mean that the game capability is complete.

Authoritative source: [original DOCX](source/Ribterra_Development_and_Steam_Plan_UA.docx), with the text copy [development-plan-ua.txt](source/development-plan-ua.txt). The `L` references below point to lines in that unchanged copy. Concept art under `source/concepts` is reference material, not implementation screenshots.

Statuses: **M0 partial** — initial prototype mechanics; **in progress** — part of the requirement is implemented, but the complete gate has not passed; **pending** — the required capability is not implemented. The **0.10 line was completed with build 0.10.1**: manual-order queues, partial group outcomes, server-side resident control, automatic session recovery, and snapshot delivery after a delayed ACK even while paused. Save 8/protocol 7/rules 7/generator 2 are preserved. Local evidence: 52/52 CTest, two final UDP profiles at 150 ms RTT and 1%/3% loss, a 36-frame GPU check, and 4/4 package smoke. Final CI `13ed5c2`: Windows 52/52, Linux 35/35, UBSan 13/13 without C++ warnings or errors. The 0.10.1 package and launcher correspond to that runtime; frame-review details and test limits are in [VALIDATION.md](VALIDATION.md). The contract is [MANUAL_ORDERS.md](MANUAL_ORDERS.md). The complete engine and every requirement below remain in force.

Historical 0.8 evidence includes local 40/40 CTest, GPU in five languages, benchmark, and package smoke; CI source commit `f62cea0` passed Windows 40/40, Linux 26/26, and UBSan 8/8. The preceding 0.7 release passed local 37/37 CTest, GPU in five languages, carrying save/resume, package smoke, and CI Windows 37/37, Linux 24/24, and UBSan 7/7. These are historical results for their named versions, not evidence for the current 0.10 code or the complete engine; current acceptance is recorded in [VALIDATION.md](VALIDATION.md).

## Current implementation sequence

1. Foundation, version/hash/ID, atomic filesystem, pinned dependencies, structured save and wire schemas.
2. Authoritative GameServer and migration of the existing game client to it; test command auth/dedupe/resources/visibility.
3. Real standalone GNS, visible full/delta, reconnect, dedicated server, LAN discovery, chat UI, durable session/autosave.
4. SDL_GPU/Renderer2D, shader/asset pipeline, and RmlUi/ICU/miniaudio without dependencies in SimCore.
5. Chunks/EnTT/logistics/AI/population, maps and diplomacy, combat/health/society/events through vertical scenarios with persistence and multiplayer validation.
6. Complete scale/performance/portability gate, Steam adapter, and real external integration tests.

## External actions

The Steam Direct fee, AppID/onboarding, tax and bank details, store review, Coming Soon page, and publication (L750–780) are separate external actions. Their presence in this document does not authorize payment, submission of legal information, or game publication. They do not block implementation of direct/LAN play or the rest of the local engine. Steam features remain unverified without the SDK/AppID and a real test.

## Objective completion rule

All mandatory document requirements remain in scope: 38 original rows plus the 3 V01–V03 additions, for a total of 41 requirements. No partial 0.10 milestone means that the complete engine is finished. Incomplete rows are not removed or renamed as optional because an intermediate build completed. A final claim that “the engine is fully complete” requires the complete L592–643 and L984–1000 gate, current evidence, and an explicit list of external limitations.
