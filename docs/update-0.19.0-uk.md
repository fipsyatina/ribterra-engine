# Ribterra 0.19.0 — самостійне життя поселення

Вільні мешканці без призначеної професії самостійно збирають відкриті ресурси поблизу, гуляють неподалік табору та розмовляють з іншими вільними мешканцями. Перші самостійні заняття починаються після короткого стартового періоду. Здобуте фізично доставляють на склад; після доставки можна змінити заняття.

Під час розмови над двома сусідами видно бульбашки. Панель мешканця показує його заняття. Це короткі соціальні анімації, без генерації текстових діалогів.

Ручні накази та призначені професії мають пріоритет. «Зупинити» вимикає самостійну поведінку; увімкнення автоматики її повертає. Харчування залишається активним під час усіх занять.

Протокол 14, правила 12. Для мережевої гри потрібна однакова версія; збереження попередньої версії підтримуються.
