# Ribterra 0.20.0

> English rendering of a historical project document, translated offline and checked for preservation of code, paths, identifiers, numeric literals, and recorded status markers. Historical records apply to their named snapshots and do not validate the current build. For exact original wording, see import commit `7388a2f`.

Each season lasts 10 in-game days. At speed 1×, daytime lasts 12 minutes and night lasts 12 minutes, for a full day of 24 minutes. At 2× and 4×, time accelerates with the simulation; pausing stops the cycle.

The game starts at 06:00. The day: 06:00–18:00, the night: 18:00–06:00. The smooth illumination of dawn and sunset changes the surface, the inhabitants, and the fog. The interface remains bright, the mine retains its own lighting.

The clock and day/night indicator appear next to the day number. Temperature remains a static indicator. Loading restores the phase from the game's ticks; for old saves, the day number is calculated using the new day length.
