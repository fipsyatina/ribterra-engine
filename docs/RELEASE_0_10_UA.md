# Ribterra 0.10.1 — завершення версії 0.10

9 вересня 2026 року. Windows x64. Приватна збірка розробки.

Версія 0.10 додає ручні черги Move/Gather, збір однієї доставки або до вичерпання ресурсу, скасування окремого наказу та передачу керування мешканцем. Shift + права кнопка додає наказ; панель **«Накази»** показує стан черги й доступні дії. Вантаж спочатку завершує фізичну доставку. Професії, навички, шахта, будівництво й попередні збереження продовжують працювати.

Фінальна збірка 0.10.1 виправляє застарілий стан клієнта на паузі після затриманого підтвердження знімка. При втраті зв’язку клієнт автоматично пробує відновити ту саму сесію. Непідтверджені накази повторюються з тим самим ID лише в межах 30 секунд і за незмінних прав сесії; це запобігає повторному ефекту. Якщо безпечний повтор неможливий, інтерфейс просить перевірити накази. Чат після відновлення не дублюється. Повідомлення доступні п’ятьма мовами.

## Запуск

У папці проєкту на робочому столі відкрийте **Play Ribterra.cmd**. Для перенесення на інший Windows x64 ПК розпакуйте `dist/Ribterra-Windows-x64-0.10.1.zip` повністю та відкрийте `Ribterra/Ribterra.exe`. Керування, збереження й direct IP наведені в [README](../README.md).

Формат збереження — 8; protocol/rules — 7; generator — 2. Збірка 0.10.1 не змінює ці формати. Попередні версії та резервні копії сейвів збережено.

## Приймання

- Локальна збірка: 52/52 CTest; остаточні профілі мережі 1% і 3% також пройдено після посилення тесту обриву.
- [CI джерела `13ed5c2`](https://github.com/fipsyatina/ribterra/actions/runs/34285248451): Windows 52/52, Linux 35/35, UBSan 13/13; C++ warnings/errors — 0.
- Два клієнти через справжній UDP: 150 мс базового RTT, втрати, дублювання, затримані пакети, обрив до автоматичного відновлення, один результат конфлікту, точні вантажі та кінцевий стан.
- D3D12 / RTX 3050 Laptop: 36 кадрів, 16 із них байт-ідентичні раніше переглянутим; 8 нових повідомлень переглянуто в п’яти мовах при 1100×700.
- Розпакований пакет: 4/4 перевірки — меню, шахта/save-resume, ручні накази та сервер із клієнтами. Окремо переглянуто меню, шахту й мережеву гру.

Точні результати, хеші та межі — у [VALIDATION](VALIDATION.md), включно з [винятком vptr для адаптера GNS](SANITIZERS.md). Пакет має runtime `27da153`; CI `13ed5c2` додає лише це налаштування санітайзера та його документацію. Мережеві профілі виконано на одному ПК; випробування 2–4 фізичних ПК і повний scale gate залишаються наступними етапами. Повний рушій, остаточний арт за концептами та Steam-реліз мають окремі вимоги. Реалізацію 0.11 у цьому завершенні не починали.
