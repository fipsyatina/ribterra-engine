# Професії та швидкість роботи 0.9

Статус: локальні, GPU, package та CI перевірки 0.9 для `d3bc785` пройдено; повторний CI `42036ff` після уточнення ініціалізаторів пройдено без C++ warnings та UBSan errors. Джерело й незмінний Windows-пакет розділено у [VALIDATION.md](VALIDATION.md). Вимоги решти професій, ручного керування та повного Utility AI залишаються у [реєстрі рушія](ENGINE_REQUIREMENTS.md).

## Досвід і вправність

Вісім незалежних навичок: лісорубство, видобуток, фермерство, будівництво, перенесення, ковальство, медицина й бій. Наявність запису навички не означає, що всі відповідні механіки вже реалізовані. Старі wood/mining/farming XP залишаються єдиними значеннями цих трьох навичок; додаткові п'ять мають окремі поля. Професія не переписує досвід.

Криві й часові параметри — у [data/skills.json](../data/skills.json). Валідатор збірки створює спільну таблицю C++ для сервера й симуляції. Канонічний JSON входить у gameplay content hash; зміна даних вимагає перебудови й перезапуску, узгоджених версій та міграції збережень. Runtime-файл не може непомітно змінити правила активного світу.

Один ігровий день має 1200 ticks. Корисна робота вимірюється цілими одиницями: 100 одиниць — стандартний робочий tick, 4000 — один XP. Повністю продуктивний день відповідає 30 XP. Поточна крива: 0 XP → −8%, 30 → −4%, 120 → 0%, 480 → +5%, 1440 → +12%, 2880 → +15%; між точками діє цілочисельна лінійна інтерполяція. Це початкові дані балансу, а не завершений баланс усієї гри.

Після трьох днів без практики починається повільне зниження вправності. За десять наступних днів втрата досягає максимуму 2 процентних пунктів. Чверть стандартного робочого дня відновлює її повністю. XP не зменшується. Навичка, якою ще не користувалися, не втрачає вигадану практику. Запит підказки не змінює стан і не оновлює timestamp; нуль корисної роботи не відновлює вправність.

Усі релевантні навички та здібності спочатку складаються, до них додається вправність, після чого застосовується **один** ліміт −1500…+1500 basis points (−15…+15%). Сервер повертає внески, суму до ліміту, застосований ефект, швидкість і ознаку обмеження. UI показує цей результат; окремої клієнтської формули досвіду немає. +15% швидкості відповідає приблизно −13% часу, а не −15% часу.

## Межа корисної роботи

Збір дає XP тільки після успішного створення фізичного результату. Очікування, постановка маршруту, повтор команди, retry й доставка не створюють ще один урожай чи XP. Будівництво зараховує лише фактично додану частку прогресу, включно з останньою неповною часткою; дробовий навчальний залишок зберігається. Пасивна Farm без виконавця не нараховує XP довільному мешканцю.

Призначення професії/пріоритетів та Stop повертають результат для кожного учасника групи. Нове призначення записується одразу; виконання перемикається після завершення поточної захищеної фізичної доставки. Стан Deferred позначає це очікування й зберігає вже прийняте призначення. Спільний зовнішній pending path не скасовується цілком через Stop одного учасника: нова політика цього мешканця очікує межі завершення пошуку. Старі Move/Gather поки мають групову атомарну відповідь; повні часткові маршрути, черга ручних наказів і передаване право контролю залишаються обов'язковими наступними роботами.

Виконувані професії цього етапу — лісоруб, шахтар, збирач, будівельник і носій. Непризначені мешканці зберігають попередню автоматичну допомогу будівництву/перевезенню. Farmer/Smith/Medic/Guard поки не мають повних робочих механік, не пропонуються у формі призначення й на рівні сервера повідомляють відсутність придатної роботи. Повний Utility AI з потребами, ризиком, соціальними причинами й вибором альтернатив після недосяжної цілі ще не готовий.

## Перевірки 0.9

Повний локальний CTest — 46/46 за 126,97 с. Після косметичного розділення hover/focus повторно пройшли всі 11 відповідних UI/render/localization сценаріїв за 40,06 с. Benchmark містить 25 успішних етапів для 10–6000 мешканців. CI `d3bc785` пройшов Windows 46/46, Linux 30/30 та UBSan 10/10; GCC повідомив про пропущені ініціалізатори. Їх явне додавання в `42036ff` зберігає семантику; локальні цільові 6/6 та повторний CI без C++ warnings/UBSan errors пройдено. Деталі, обмеження й точні результати — у [VALIDATION.md](VALIDATION.md).
