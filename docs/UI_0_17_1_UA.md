# Ribterra 0.17.1 — building menu

> English rendering of a historical project document, translated offline and checked for preservation of code, paths, identifiers, numeric literals, and recorded status markers. Historical records apply to their named snapshots and do not validate the current build. For exact original wording, see import commit `7388a2f`.

The vertical panel is placed on the left: the hammer opens and closes the single construction catalog, the column opens the inventory. The categories and icons of buildings are shown only together with the catalog. The choice of building closes the menu and starts placement. The double-speed directory at the bottom left is deleted.

The names use the static fat weight 700 Cormorant Garamond instead of the original 300. Prices are increased from 10 to 13 dp and made more contrasting. The catalogue has three columns and a scroll; The panel of selected residents has been moved from the vertical menu.

Network formats, storage and simulation rules remain unchanged.
