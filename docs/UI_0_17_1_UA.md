# Ribterra 0.17.1 — меню будівництва

Ліворуч розміщено вертикальну панель: молоток відкриває та закриває єдиний каталог будівництва, колосок відкриває запаси. Категорії та іконки будівель показуються тільки разом із каталогом. Вибір будівлі закриває меню й починає розміщення. Дубль швидкого каталогу знизу ліворуч видалено.

Назви використовують статичну жирну вагу 700 Cormorant Garamond замість початкової 300. Ціни збільшено з 10 до 13 dp та зроблено контрастнішими. Каталог має три колонки й прокручування; панель вибраних мешканців зміщено від вертикального меню.

Формати мережі, збережень та правила симуляції не змінені.
