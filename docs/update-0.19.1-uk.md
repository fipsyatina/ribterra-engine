# Ribterra 0.19.1

Затиснута ЛКМ і перетягування виділяють рамкою юнітів поточного шару. Alt + ЛКМ додає окремого юніта; Alt із рамкою додає групу. Shift також підтримується для сумісності. Повторне додавання не знімає виділення.

Перетягування завершується навіть над панелями інтерфейсу. Escape скасовує рамку, втрата фокуса та перемикання шару скидають захоплення миші. Рамка не запускається під час розміщення будівель.
