# Ribterra 0.19.1

> English rendering of a historical project document, translated offline and checked for preservation of code, paths, identifiers, numeric literals, and recorded status markers. Historical records apply to their named snapshots and do not validate the current build. For exact original wording, see import commit `7388a2f`.

The compressed LCM and the overdraft are separated by the current layer's unit frame. Alt + LCM adds a separate unit; Alt with the frame adds the group. Shift is also supported for compatibility. Re-addition does not remove the subtraction.

The drag is even completed over the interface panels. Escape eliminates the frame, loss of focus and shifting the balls reduce the mouse's grip. The frame is not launched when the buildings are placed.
