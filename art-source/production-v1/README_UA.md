# Ribterra — набір вихідного арту 2026-09-09

Оновлення 0.11.1: з прямого дозволу користувача підготовлені runtime-копії цих аркушів. Оригінали в цій папці залишилися незмінними. Поточна інтеграція описана в `docs/ART_0_11_1_UA.md` від кореня проєкту; технічний статус нижче описує саме вихідні PNG.

Намальовано вбудованим image_gen без субагентів. Зображення створені та виправлені виключно генератором. PNG скопійовані без зміни пікселів; скрипти використовувалися тільки для збереження, читання заголовків/хешів та текстової галереї. Вихідні концепти не змінено.

## Перегляд

Відкрийте index.html у браузері. Зліва — категорії, поруч з аркушем — незмінений авторський концепт. Кнопка «Оригінальний розмір» показує зображення без підгонки під ширину. Галерея працює локально без зовнішніх бібліотек і мережевих сервісів.

## Фактичний технічний статус

- Усі 10 збережених файлів — PNG RGB (color type 2), без alpha. Для об'єктних аркушів генератор створив темне тло. Воно є частиною зображення.
- Це вихідні арт-аркуші, а не готові runtime-атласи з перевіреною прозорістю й координатами.
- Генератор не дотримався запитаних точних розмірів. Фактичні розміри, байти й SHA-256 наведено в files.json.
- Сітка в промптах — опис розкладки. Точні прямокутники, спільні pivots, padding/extrusion та відповідність footprint не калібровані. Автоматичне рівне нарізання без перевірки не рекомендоване.
- Літня й зимова версії намальовані як та сама споруда; попіксельна сталість силуетів між станами не гарантована.
- Юніти мають статичні пози та два ракурси; ходьба, робота, бій і повний набір напрямків не намальовані.
- Курсори намальовані в аркуші, але окремі cursor-файли, hotspot і системна інтеграція не створені.
- Поверхні запитано як tileable, але безшовність не перевірена. Вода не анімована.
- У fog-masks біле означає непрозорий туман, чорне — відкриту ділянку. Це RGB-маски; в грі треба читати яскравість як маску, а не alpha. Розкладку й стикування переходів ще потрібно перевірити.
- UI є артом компонентів; 9-slice, інтерактивні стани й локалізований текст не інтегровано. Заповнення індикаторів генератор намалював разом із рамкою.
- Чинний код гри та runtime asset registry цим набором не змінені. Раніше наявні локальні зміни збережено.

## Візуальна перевірка

Усі оригінальні результати переглянуто після генерації. Окремо у підключеному браузері перевірено галерею: перемикання на громадські споруди, відображення поруч із концептом, перемикання на іконки та прокручування до всіх шести курсорів. Це перевірка арту, не перевірка ігрового рендера й не твердження про повну відповідність концепту.

Рослинність та іконки отримали цільове виправлення тла генератором; в іконках також пом'якшено надто товстий контур. Скриптова обробка зображень не застосовувалась за прямим вибором користувача.

## Відтворення та джерела

production-plan.json містить початкові промпти та запитану розкладку. generation-edits.json — промпти двох уточнень. files.json — відомості про фактично збережені файли. references/ містить незмінені копії п'яти авторських концептів для автономного порівняння.
